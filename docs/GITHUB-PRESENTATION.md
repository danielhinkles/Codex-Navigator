## Page structure

Pitch → app screenshot → four benefits → three-step workflow → installation → data boundaries → optional features → documentation → licence.

The README is the introduction. Installation details live in INSTALL.md; the User Guide holds interaction details; the Technical Reference holds implementation details. Keep each behaviour’s descriptions consistent when updating these files.

## Short announcement copy

Codex Navigator brings local Codex history into a native Mac library. Search earlier prompts, organise projects your way, preview the work, and continue a task from the same window. Builds from source on macOS 14 or later. Browsing needs no separate API key or model call; task submissions use your installed Codex configuration.
